## Rangfolge

Es gilt die Autorität nach Zuständigkeit (`CLAUDE.md` §4). Explizite aktuelle
Anweisungen von Stephan gehen vor. Bei visuellen Fragen gilt die Rangfolge im
[Design System](design/design-system.md).

Echte Konflikte werden nicht stillschweigend entschieden, sondern offen
angesprochen und bei Bedarf in einer ADR oder den offenen Fragen festgehalten.
