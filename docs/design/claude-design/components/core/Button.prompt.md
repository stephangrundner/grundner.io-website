Primäre Aktion einer Sektion; orange Fläche mit schwarzem Text, maximal ein primary pro Sichtbereich.

\`\`\`jsx
<Button variant="primary" href="/kontakt">Projekt besprechen</Button>
<Button variant="secondary">Projekte ansehen</Button>
<Button variant="secondary" onDark>Projektprofil</Button>
\`\`\`

Varianten: `primary` (Orange), `secondary` (Outline, füllt beim Hover), `tertiary` (Text). Größen `sm | md | lg`, alle mit mindestens 44px Höhe. `onDark` für Graphitflächen, `href` rendert einen Link.
